# Experiment 0 results

Each calibration run must use its own versioned subdirectory. The current
development configuration writes to `development_full_v2/`. The runner refuses
to overwrite an existing directory.

Results generated by the superseded three-layer prototype were removed because
they do not satisfy the current Experiment 0 protocol. See
`code/calibration/experiment_0/README.md` for artifact definitions and commands.
